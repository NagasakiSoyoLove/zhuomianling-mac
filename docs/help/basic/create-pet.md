桌面灵的每一只桌宠都有自己的资料。先给它创建一份资料，再逐项补充模型、AI、人设和声音设置即可。

## 从主页开始

![创建桌宠时的基础信息页面](./images/create-pet-form.png)

在主页点击“创建新桌宠”，会进入“基础信息”页面。按下面的顺序填写：

1. 在“名称”中填写一个便于区分的名字，例如 `示例`。
2. 点击左侧的头像区域，选择一张 PNG、JPG、JPEG 或 WebP 图片作为列表头像。
3. 检查名称和头像后，点击右下角“保存”。

保存成功后，这只桌宠就会出现在主页列表中。名称和头像只用于在列表中识别它，不会直接改变它的行为；之后进入编辑器仍然可以继续修改。

## 创建完成后

创建完成后，可以从左侧进入“Live2D”导入模型，再到“LLM 配置”连接 AI。即使暂时没有模型或 AI，也可以先编辑主题、人设、事件和快捷操作。

> 小提示：每只桌宠的设置彼此独立，切换桌宠不会覆盖另一只桌宠的配置。
