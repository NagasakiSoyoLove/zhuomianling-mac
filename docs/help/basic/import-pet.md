桌宠包适合把桌宠设置带到另一台电脑，也适合做一份可恢复的备份。导入和导出都从主窗口发起。

## 导入桌宠包

![主页上的导入桌宠入口](./images/home-overview.png)

1. 回到主页，点击顶部的“导入桌宠”。
2. 点击“选择 .zmling 文件”，选择要导入的桌宠包。
3. 等待桌面灵完成文件完整性和资源安全检查。
4. 检查通过后，向导会根据桌宠包内容进入 AI 配置、语音配置或安装步骤。

### 选择并检查桌宠包

![导入桌宠包的选择与检查页面](./images/import-pet-package-check.png)

选择文件后，桌面灵会先检查文件是否完整、安全，再检查压缩包中的路径、大小、资源类型以及 Live2D、语音资源和主题是否齐全。检查阶段不会覆盖现有桌宠；如果检查失败，可以更换文件后重新开始。

导入前请确认桌宠包来自可信来源。桌宠包中的 AI 密钥、连接信息、记忆和对方电脑上的文件路径不会导入。

### 配置导入后的 AI 连接

![导入流程中的 AI 配置页面](./images/import-pet-ai-config.png)

如果桌宠包需要 AI，向导会进入“AI 配置”步骤。这里需要重新填写连接信息：

1. 在“服务”中选择服务类型；如果服务不在列表中，选择“自定义”。
2. 填写服务提供方的 Base URL 和 API Key。
3. 点击“获取模型列表”，从返回的模型中选择要使用的模型。
4. 完成模型和回复能力检测后，点击“下一步”继续。

桌宠包不会携带原作者的 API Key 或连接信息。只有在安装成功后，你填写的连接信息才会保存到当前电脑的安全配置中；如果暂时不使用 AI，可以返回并取消本次导入。

### 语音配置与安装

如果桌宠包包含 GPT-SoVITS 资源，下一步会要求选择当前电脑上已经准备好的 GPT-SoVITS 文件夹。桌面灵会检查运行所需的文件和模型；检查通过后，向导会进入“安装”步骤。不包含语音资源的桌宠包会跳过这一步。

在安装前，向导会显示桌宠名称、Live2D、AI 和语音资源的检查结果。确认无误后点击“安装桌宠”，安装完成的新桌宠会加入主页列表。

## 导出与备份

在主页选择一只桌宠后，可以从编辑器右上角的“导出桌宠”创建桌宠包。导出的内容用于迁移和备份；API Key 等密钥信息不会被打进包里，换到新设备后需要重新配置连接。

> 导入别人分享的桌宠包前，请确认其中的模型、音频和其它资源拥有合法授权。
