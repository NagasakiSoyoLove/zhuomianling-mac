连接 AI 后，当前桌宠才能聊天和使用需要 AI 的功能。Live2D、主题和事件不依赖 AI，可以先完成其它设置，之后再回来连接。

## 填写连接信息

![AI 服务连接信息](./images/ai-connection.png)

在左侧展开“AI 设置”，进入“LLM 配置”，按页面中的三个区域完成设置：

1. 选择 AI 服务商。使用其它兼容服务时，可以选择“自定义”。
2. 填写服务地址（Base URL）和 API Key。已经保存的 Key 会显示为“已安全保存，留空不修改”，不需要每次重新输入。
3. 点击“获取模型列表”，在“选择模型”区域选择要使用的模型。

保存后，页面顶部会显示连接状态。API Key 只保存在当前电脑的安全配置中，不会写入教程、桌宠包或发布文件。

## 选择模型并测试能力

![AI 模型与能力检测结果](./images/ai-capabilities.png)

在“当前能力”区域点击“测试 AI 回复”，确认连接正常，以及当前模型是否支持一次性完成回复、边生成边显示等功能。测试使用的是固定的测试内容，不会进入聊天记录、语音或记忆书。

如果后续要使用视觉功能，请在这里选择支持图片理解的多模态模型，再到“视觉功能”页面检测图片理解能力。普通文字模型即使能正常聊天，也不一定支持识图。

> 如果服务商兼容 OpenAI Chat Completions 格式，通常可以直接使用兼容模式配置。
