Live2D 模型要导入到当前正在编辑的桌宠。导入完成后，桌面灵会检查主模型文件、贴图、动作和表情，并把结果显示在页面上。

## 选择模型文件夹

![Live2D 导入与资源检查页面](./images/live2d-import.png)

1. 打开当前桌宠编辑器，在左侧点击“Live2D”。
2. 点击右上方“导入新模型”，选择模型所在的文件夹。
3. 选择文件夹中的 `model.json` 或 `.model3.json` 主文件，等待页面完成检查。
4. 看到“资源完整”后，在预览区域确认模型能正常显示，再点击保存。

页面会根据主文件自动判断模型类型。不要只选择贴图或动作文件夹，否则模型会缺少启动所需的主文件，无法正常导入。

## 导入后检查

导入成功后，页面会显示主文件、贴图数量、动作数量和表情数量。动作和表情会自动检查，之后可以在“表现映射”和“事件配置”中继续使用；也可以在当前页面点击“测试动作/表情”确认资源是否正常。

> 模型资源的版权和使用许可由资源提供者决定，请只导入你有权使用的文件。
