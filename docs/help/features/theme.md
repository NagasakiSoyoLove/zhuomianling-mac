主题风格控制当前桌宠的主窗口、编辑器和聊天界面的颜色、背景、卡片和按钮风格。每只桌宠单独保存自己的主题，切换桌宠后可以使用另一套风格。

## 选择内置主题

![主题风格选择页面](./images/theme-style.png)

在“交互面板 → 主题风格”中选择喜欢的主题卡片。选中后会立即看到预览变化，点击右下角“保存”才会应用到当前桌宠。主题切换不会影响模型、人设、AI 或声音设置。

## 导入自定义主题

点击页面顶部“导入主题风格”，选择主题文件后先检查预览，再保存。自定义主题会先放在当前桌宠的未保存内容中；只有保存后才会生效。切换内置主题不会自动删除已经导入的自定义主题。
