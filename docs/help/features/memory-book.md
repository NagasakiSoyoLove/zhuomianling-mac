记忆书用于查看和管理当前桌宠记住的长期内容。它和普通聊天窗口分开，进入记忆书时会从目录开始新的阅读。

## 从目录开始阅读

![记忆书目录页](./images/memory-book.png)

记忆书顶部会显示当前桌宠的名称和记忆状态，方便你确认记忆是否已经准备好。中间的“目录、你、习惯、事件、目标”是阅读入口：

- “目录”查看四个章节和每章的记录数量。
- “你”和“习惯”查看称呼、偏好和稳定互动方式。
- “事件”和“目标”查看共同经历、承诺和长期目标。

从主页再次进入记忆书时，会重新回到目录，不会继承上一次阅读的章节、搜索条件或页码。

## 开始使用

第一次进入时，应用会说明三个选项的作用：

- 召回：聊天时允许桌宠参考相关记忆。
- 自动整理：在符合条件的聊天结束后，自动整理可能值得长期保留的内容。
- 保留来源：同时保留生成记忆所依据的原始对话，方便之后核对。

只有点击确认启用后，选择才会保存；暂不启用不会替你修改配置，下次进入时仍然可以重新选择。

## 搜索、编辑与忘记

可以使用顶部搜索框按正文或标签查找，也可以按时间筛选、按重要程度过滤。打开一条记忆后可以编辑内容，或使用“忘记”；短暂撤销时间内可以恢复误操作。每只桌宠的记忆彼此分开，不同桌宠不会互相参考。

## 导出记忆

在记忆书顶部点击“导出”，把当前桌宠的记忆保存到你选择的位置。导出由应用完成，页面不会把你的本机文件路径显示出来。

> 记忆可能过期或不完整；桌宠会优先听从你当前的新表达。
