每只桌宠都有自己的心情。你的操作、事件和 AI 回复带来的情绪变化都可能影响它；一段时间没有新的变化时，心情会慢慢回到平静。

## 设置心情区间

![心情区间配置页面](./images/mood-editor.png)

页面固定提供七个区间：黑化、低迷、失落、平静、愉快、喜悦和兴奋。先在顶部选择一个区间，再配置该区间的内容：

1. 选择进入这个区间时播放的动作或表情。
2. 填写进入这个区间时显示的台词。
3. 如果需要语音，添加该区间的参考音频；没有单独设置时，会自动使用更接近平静的可用声音。
4. 保存当前区间，再切换到其它区间继续设置。

## 观察心情变化

桌宠窗口会显示当前心情。具体数值不会写进聊天正文、字幕、语音内容或记忆书；它只用于选择对应的动作、表情和语音。
