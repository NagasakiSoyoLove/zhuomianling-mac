表现映射是把“某种语气或反应”对应到模型动作、表情的地方。这样 AI 或事件需要表达开心、害羞、生气等反应时，桌宠就能播放你指定的表现。

## 建立映射

![表现映射页面](./images/expression-mapping.png)

进入“表现映射”后，页面会按“动作”和“表情”分开列出已经找到的内容。每一行都会显示文件名、预览按钮、映射 key 和说明：

1. 点击预览确认这一行对应的动作或表情。
2. 在“映射 key”中填写一个唯一的英文名称，例如 `greeting` 或 `happy`。这是这条动作或表情的使用名称，之后会在事件配置中用到。
3. 在说明中写清楚它适合表达的语气或场景，方便你自己查找，也方便 AI 选择。
4. 保存后，再到“事件配置”中使用这些名称。

映射 key 必须以英文字母开头，只能使用英文、数字、下划线或短横线，同一只桌宠不能重复。

## 找不到可用表现时

先确认模型已经成功导入，并在 Live2D 页面重新检查动作和表情。替换模型后，只有原来找不到资源的动作或表情需要重新选择，人设、AI 和声音设置会保留。
