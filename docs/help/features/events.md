事件配置可以让桌宠在特定情况发生时做出反应，例如模型加载完成、点击模型、连续快速点击或拖拽模型。

## 添加一个事件

![事件配置页面](./images/events-editor.png)

每张事件卡片都可以单独设置：

1. 选择要播放的动作或表情。
2. 添加一条或多条备用台词。
3. 根据需要打开“显示气泡”和语音选项。
4. 点击卡片右上角的播放按钮预览效果。

动作和表情只能从当前桌宠已经导入并检查到的资源中选择。台词可以准备多条，事件触发时桌面灵会从你写好的台词中选择一条。

## 调整事件

先配置模型加载完成、点击模型这类核心事件，再逐步增加快速点击、拖拽等互动事件。修改完成后点击页面右下角“保存”；只预览不会写入配置。
