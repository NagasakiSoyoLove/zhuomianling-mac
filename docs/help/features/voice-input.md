语音输入会把你主动说出的内容转换成文字，再交给桌宠聊天。它是可选功能，录音需要你点击麦克风按钮触发，不会在后台监听。

## 先准备腾讯云语音识别

腾讯云实时语音识别可以免费使用。注册并开通后会赠送多份免费资源包，之后通常每个月还会赠送一次免费资源；资源包的具体数量、有效期和当前活动规则，以腾讯云控制台显示为准。

[打开腾讯云语音识别控制台](https://console.cloud.tencent.com/asr)

### 1. 进入语音识别页面

打开控制台后，在语音识别概览页找到“开始使用 ASR”区域，在第一步“创建秘钥”中点击“创建密钥”。

![第一步：点击创建密钥](./images/tencent-asr-overview.png)

### 2. 创建并保存 SecretId、SecretKey

创建后会弹出密钥窗口，里面会同时显示 `SecretId` 和 `SecretKey`：

1. 先把两项内容复制到只有你自己能访问的密码管理器或安全文件中。
2. `SecretKey` 创建后通常不能再次查询，确认已经保存好再继续。
3. 勾选“我已知晓并保存 SecretKey”，然后点击“确定”。也可以使用“下载 CSV 文件”留存，但不要把 CSV 上传到网盘、代码仓库或发给他人。

![第二步：保存 SecretId 和 SecretKey](./images/tencent-secret-key-created.png)

图中的 SecretId 和 SecretKey 已做遮挡，实际操作时请保存你自己账号生成的内容。

### 3. 查看 AppID

如果需要确认账号的 `AppID`，进入“访问管理 → API 密钥管理”。在已创建密钥的表格中，`SecretId` 所在行的 `APPID` 列就是要填写到桌面灵里的 AppID。

![第三步：在 API 密钥管理中查看 AppID](./images/tencent-api-key-management.png)

这里的名称是 **AppID**，不是 Apple ID。截图里的 SecretId 和 AppID 已经做遮挡；请以你自己控制台显示的值为准。

## 回到桌面灵填写连接信息

先确保已经保存一只桌宠，然后进入它的编辑页面，打开左侧“语音系统 → 语音输入”。

![语音输入服务连接页面](./images/voice-input-connection.png)

在“腾讯云实时语音识别”区域填写三项内容：

- `AppID`：在 API 密钥管理页面查看到的账号编号。
- `SecretId`：刚刚创建并保存的密钥 ID。
- `SecretKey`：刚刚创建并保存的密钥内容；输入框会以密码形式显示。

三项都填写后点击“连接”。右上角状态变为“已连接”后，下面的语音输入选项才会启用。已经保存过密钥时，输入框会显示“已安全保存，留空不修改”，修改其它选项时不需要再次输入。

## 保存并调整识别方式

连接成功后，按自己的环境调整选项，最后点击页面底部的“保存”。

![语音输入参数页面](./images/voice-input-options.png)

- “自动识别说话结束”：开启后，检测到持续静音会自动结束录音并提交识别。
- “静音超过多少时间自动结束”：可在 0.4–2 秒之间调整。说话停顿较多时可以调大，想更快提交时可以调小。
- “音量阈值”：可在 4%–45% 之间调整。普通房间可以先从 18% 左右开始；环境越吵，阈值越高，声音越轻，阈值越低。
- “回复后继续录音”：适合连续对话。开启后，语音发送并收到 AI 回复后会自动重新打开录音。

如果“自动识别说话结束”关闭，相关的静音时间和音量阈值滑杆会暂时不可调整；你仍然可以再次点击麦克风按钮手动结束录音。

## 开始使用

打开桌宠聊天框，点击麦克风按钮开始录音。再次点击，或等待应用检测到说话结束后，录音会停止并进入识别阶段；转换出的文字会作为一条聊天消息发送给桌宠。

语音输入必须由你主动触发。关闭聊天框、桌宠窗口或应用时，当前录音也会停止。
