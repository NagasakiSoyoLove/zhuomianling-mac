主页是选择、启用和管理桌宠的地方。桌宠窗口负责陪伴和聊天，主页负责设置，两者可以同时打开。

## 主页上有什么

![桌宠主页与列表](./images/home-overview.png)

顶部的“帮助中心”用于打开教程，“导入桌宠”用于导入桌宠包，右侧状态会提示当前是否有桌宠正在运行。左侧列表中的每张卡片会显示头像、名称和简介。

## 选择与编辑

点击左侧桌宠卡片后，右侧会显示预览、启用状态和“编辑”按钮。进入编辑器后，左侧导航会按“基础信息、Live2D、交互面板、AI 设置、语音系统”等分组展示设置页面；修改后要点击对应页面的“保存”才会生效。

## 启动桌宠

点击桌宠卡片上的“启用”即可打开透明桌宠窗口。关闭桌宠只会关闭运行窗口，不会删除它的设置；回到主页后仍然可以再次启用。
